## O que este repositório NÃO é

- não é branch de desenvolvimento do SAGA;
- não é runtime;
- não é Curriculum Graph soberano;
- não é backlog automático;
- não é autorização para implementar propostas;
- não transforma pesquisa em cânone por existir aqui.

## Hierarquia epistemológica

1. GitHub remoto + código + gates do SAGA produtivo vencem fatos de implementação.
2. Cânone pedagógico vigente do SAGA vence identidade/metodologia.
3. Decision Ledger reconciliado vence propostas antigas desta Foundry.
4. O Registro Reconciliado de Detalhe preserva microdecisões e insights, mas continua pré-canônico.
5. Pesquisas e auditorias externas alimentam decisões; não são autoridade.
6. Protótipos `.ts` em `06_research/` são material de estudo, não patches prontos.
