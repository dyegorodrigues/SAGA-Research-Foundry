# North Star

> O SAGA deve formar uma criança que sabe como começar quando ainda não sabe a resposta.

O objetivo não é prometer “gênio” como rótulo.
O objetivo verificável é construir:
- domínio matemático profundo;
- fluência;
- autonomia estratégica;
- representação/modelagem;
- debugging;
- transferência;
- robustez;
- aprendizagem futura com menor atrito.

## Visão longitudinal
A criança vive estruturas cognitivas antes dos nomes formais.
Depois reconhece essas estruturas em:
matemática → programação → engenharia → robótica → dados → IA.

## Princípio
> Analogia estrutural não é identidade conceitual.

AL.02 não “é loop”.
Ele pode formar uma ponte para repetição algorítmica sem deixar de ser matemática.
