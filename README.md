# SAGA Research Foundry

Workspace persistente de **P&D, arquitetura, engenharia pedagógica, pesquisa, decisão e handoff** do ecossistema SAGA.

Este repositório NÃO é o produto SAGA e não substitui o repositório de runtime.

## Relação entre repositórios

- **Produto / runtime:** `dyegorodrigues/SAGA`
- **Workspace de P&D:** `dyegorodrigues/SAGA-Research-Foundry`
- **Creature/Pokémon sandbox existente:** `dyegorodrigues/PokeSagaLab`

## Regra de ouro

> O SAGA produtivo responde “o que existe e funciona agora?”.  
> A Foundry responde “o que estudamos, projetamos, decidimos, rejeitamos, validamos e pretendemos experimentar?”.

Nada neste repositório autoriza automaticamente alteração no SAGA produtivo.
