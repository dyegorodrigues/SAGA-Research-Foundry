# AGENTS.md — Regras de trabalho para agentes

## Papel padrão
`READ-ONLY ARCHITECT / RESEARCHER`

Um agente só vira writer do SAGA produtivo com autorização explícita do usuário em outra frente.

## Escrita nesta Foundry
Permitida quando a tarefa pede:
- pesquisa;
- consolidação;
- arquitetura;
- documentação;
- Decision Ledger;
- experimentos conceituais;
- handoff.

## Proibições
- não alterar `dyegorodrigues/SAGA` por consequência implícita;
- não tratar proposal como cânone;
- não criar hard unlock de Thinking;
- não criar score de inteligência;
- não inferir condição clínica;
- não usar RT/velocidade como mastery;
- não duplicar Tutor/Composer/Grafo sem prova de necessidade.

## Regra de redução
Antes de propor novo motor/componente:

> Se apenas reutilizarmos o que existe + metadados/evidência mínima + 1–3 bridges, quanto do valor pedagógico sobrevive?

Se a resposta for “quase tudo”, não criar a infraestrutura adicional.

## Atualização de sessão
Toda rodada significativa deve:
1. atualizar `07_handoffs/SESSION_LOG.md`;
2. atualizar Decision Ledger se houve decisão;
3. atualizar backlog se surgiu pergunta;
4. atualizar CURRENT_STATE apenas quando fatos externos forem revalidados.
